# database/migrations

Plain SQL migration files, generated by `drizzle-kit` from the table definitions in `apps/core-api/src/database/schema.ts` — not hand-written.

```bash
# after editing schema.ts:
pnpm --filter @folkshops/core-api db:generate   # writes a new .sql file here
pnpm --filter @folkshops/core-api db:migrate    # applies pending migrations via MIGRATIONS_DATABASE_URL
```

Empty until the tenancy slice adds the first tables (tenants, users, memberships).
