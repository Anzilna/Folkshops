# @folkshops/merchant-admin

Merchant admin dashboard — Next.js (App Router) + Tailwind CSS v4.

Scaffolding only — no real pages yet. Will need auth against `core-api`'s `/auth/login` once wired up.

## Local development

```bash
pnpm --filter @folkshops/merchant-admin dev
```

Runs on http://localhost:3000 (or the next free port if run alongside other apps).
